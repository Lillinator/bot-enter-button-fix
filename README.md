# bot-enter-button-fix
Discourse theme component that reverts the enter button to it's standard start new line behaviour in the initial post of bot topic conversations.

This simple theme component reverts the annoying enter button submission behaviour on the first post message in conversations with the Bot in the Discourse AI plugin (messages, not chat).  Submitting the first post message to the Discourse AI bot will require clicking/tapping the paper-plane icon. 

There are no settings. Simply install the theme component as usual and refresh your browser.
