# bot-enter-button-fix

⚠️ this component is deprecated - ther is now a core setting in user preferences which can toggle the feature on and off: https://meta.discourse.org/t/bot-enter-button-fix-for-discourse-ai/408513/3?u=lilly

Discourse theme component that reverts the enter button to it's standard start new line behaviour in the post of bot topic conversations.

This simple theme component reverts the annoying <kbd>Enter</kbd> button submission behaviour for messages in conversations with the Bot in the Discourse AI plugin (messages, not chat).  Hitting <kbd>Enter</kbd> goes to a new line, while submitting the  post message to the Discourse AI bot will require clicking/tapping the paper-plane icon. 

There are no settings. Simply install the theme component as usual, add it to your selected themes, and refresh your browser.
